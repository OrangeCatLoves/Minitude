# Licences

## Fonts (in `packages/web/public/fonts`)

- **Pixelify Sans** by Stefie Justprince, SIL Open Font License 1.1. The files named `PixelifyFix-*.ttf` are static instances of Pixelify Sans (weights 400, 500, 600, 700) with one glyph patched so the digit "5" can be told apart from "S". Because the OFL reserves font names only when declared, check the upstream licence text before redistributing the patched files under the name "Pixelify".
- **Silkscreen** by Jason Kottke, SIL Open Font License 1.1 (Regular and Bold).

The OFL allows use, embedding and redistribution (including commercial) as long as the licence text travels with the fonts and the fonts are not sold on their own. Add the full OFL text files next to the fonts before you publish.

## Libraries

Installed from npm, not copied into this repository. The main ones: Hono (MIT), `better-sqlite3` (MIT; it bundles SQLite, which is public domain), Vite, TypeScript, Vitest, Playwright (tools only). Run `npm ls` for the full list; check their licences before you publish.

The Gemini API has its own terms of use and rate limits: read them at <https://ai.google.dev> before you open the game to the public.
