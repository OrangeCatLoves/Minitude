MINITUDE: TAB ICON DRAFTS

Six ideas for the small picture in the browser tab. Each is drawn on a 16 x 16 pixel grid, like the game's own pixel art, so it stays sharp at tab size. Every card shows the icon enlarged, then at its real size in a light and a dark browser tab, and bigger for bookmarks and a phone's home screen. Tell me the letter you like (or what to change: colours, a mix of two).

The same picture would also be used when someone saves the game to a phone's home screen or bookmarks it. Nothing here is in the game yet.
